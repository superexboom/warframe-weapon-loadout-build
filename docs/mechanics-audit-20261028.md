# 武器机制审计与修复（2026-10-28）

本轮检查远程与同伴武器的伤害组件、投射物生命周期、弱点字段、触发事件以及缓存有效性。修复依据是保存的原生数据、局部反汇编、独立伤害算式和回归测试。**本轮没有进行游戏内伤害实测；Python/Rust 一致不代表两者共同采用的机制一定正确。**

## 证据范围

- 原生样本构建：`2026.10.22.13.12`。这是保留样本的构建号，不是当前在线版本声明。
- Packages SHA-256：`00ca82217ae21bafb31133165b8e3ea098c048783c14958fdfe23f76288bfa06`。
- 客户端 EXE SHA-256：`eec0dbd7078cd6e1f2402fc953ec2741e87a6fb2658ec288be195aac75a1e76d`。
- 资源目录解析：468745 条记录、468744 个唯一路径；所选资源均通过结构校验，不能将零条提取视为成功。
- 矩阵以当前 Portable 目录为范围：412 把远程/同伴武器、619 个显式伤害模式，每个模式运行身体裸装、头部火多重、腐蚀混合防御池、爆炸多重四种场景，共2476例，每例8秒。
- 范围不含近战动画、Tennokai、极化，也不覆盖未导出的模式、所有配装组合或真实弹道空间分布。

## 能独立核算的结果

- Atomos无MOD、4秒、固定无甲目标的六发测试：总伤害由816.0791变为4789.5684（含状态）。这说明原模型存在实质漏伤，不是优化器搜索深度的差别。
- Alternox无暴击/状态、单弹体：5秒引爆为约50直击+5×50场伤+100终爆=400；Prime为70+5×70+140=560。自然10秒到期分别650/910。浮点原始50/70保留源值尾差。
- Cryotra无暴击/随机状态、单弹体、活目标4.5秒：10+5×20=110。
- Riot-848单发无额外增益：12+48=60，再施加该模式实际暴击期望。
- Alternox+rank5 Arcane Acceleration、crit SET1/status SET0、立即引爆：原来多重2.2在裁剪后仍将首发赋能概率从0.510000014抬到0.680615594，1.5秒从3发变4发。现在保守裁剪分支与1弹体基准相同，两个引擎均由独立回归锁定。

## 验证与发布边界

最终测试与输入/原生核心指纹记录在[evidence/mechanics-audit-20261028/summary.json](evidence/mechanics-audit-20261028/summary.json)。矩阵只用于确认两个引擎一致；新增独立算式、触发和主体规则测试用来捕获两边共同的错误。

上一轮全量测试中缓存刷新失败来自测试直接调用独立烘焙worker后留下全局no-op。已修复测试隔离，按原顺序复测通过，没有为了通过测试放松缓存版本/输入校验。

本轮交付源代码、数据修正、测试及证据摘要。当前变更会使旧评分缓存失效，现有已发布v2026.10.28和Bot缓存不能当成本轮修复的验证结果。后续缓存/组件打包需使用同一份新源码和重建的原生核心，完成新指纹对应的烘焙再发布。GPU通用状态回放及候选批处理仍属独立未完成工作，本轮没有新增生产GPU加速结论。
