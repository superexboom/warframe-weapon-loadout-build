# Narin 补全（2026-10-12）

Narin（内部名 Duelist，语言目录 Iceblade）是 Update 44「Iceblade of Narin」（2026-09-23）的第 66 个战甲，晚于本地冻结的
2026.08.13 数据。09.22 从引擎转储加进 sidecar 的那一行只有占位名、相对路径的技能、没有技能数值和图标，极性也放错了位置。

## 数据来源

|内容|来源|
|---|---|
|英文技能名（Neote / Naraemagi / Hakchum / Nurinarim）、哪个技能可被注入（Neote）|Overframe `db/items`、`db/abilities`（10-01 的构建）|
|技能数值、能量消耗、英文描述、被动|官方 wiki 各技能页的信息框（逐字取原文）|
|中文技能名与描述、战甲描述|warframe.com/zh-hans 官方页面|
|极性、等级成长（+100 生命 / 护盾 / 能量）、技能本地化标签、注入蓝图|本机游戏缓存 10.08 的 Packages.bin|
|头像与四个技能图标|本机游戏缓存的贴图（导出工具从 Texture 包取 PNG）|

Overframe 主站有 Cloudflare 人机验证，取的是它 CDN 上的静态数据块：用 Wayback 存档的 10-01 首页找到当时的 webpack
清单，再从清单里的块名下载。它的技能数值表（`abilitystats`）10-01 时还是 08-31 那一版，没有 Narin；它给的极性
（Naramon 位在第 5 槽、双 Madurai）与客户端和 wiki 都对不上，以客户端为准。

## 结果

- 名称：Narin；技能：寒霜疾剑、冰翎御盾、鹤影舞坠、降灵旋刃，能量 25 / 50 / 75 / 25（降灵旋刃另需满冰能量）。
- 面板：270 / 550 / 165 / 200 → 30 级 370 / 650 / 165 / **300**（原来按通用成长算成 250）。
- 极性：光环 Naramon，Vazarin 与 Madurai 各一槽，无 Exilus 极性（原来光环写成通用、普通槽错位）。
- 每个技能的数值行（共 39 行）带强度 / 持续 / 范围 / 效率缩放来源；Intensify +30% 时寒霜疾剑每击 400 → 520。
- 寒霜疾剑加入 Helminth 可注入列表（注入版的专属描述拿不到，沿用原描述，标记为仅文本）。
- 配装页外部加成新增「Narin · 鹤影舞坠」：冰冻伤害易伤 +150%（受强度），只乘直伤中纯冰冻的部分（复合元素里的冰冻不算）。

## 没做 / 近似

- 寒霜疾剑的锥形角度：wiki 也是「?」，标为未解析字段。
- 被动给主副武器的额外冰冻伤害：数值写在 `DuelistPassive.lua` 里（复用 Cyte-09 补给的元素弹药升级），没有来源给出数字，
  只写了说明，没有建模。中文被动说明是按 wiki 英文翻译的（客户端语言包未解码）。

## 顺带修正

`tools/sync_warframe_client_fields.py` 按客户端核对了全部战甲的 30 级成长与极性：

- Yareli / Yareli Prime：30 级面板原来与 0 级相同，改为 370 / 555 / 300 与 370 / 650 / 315（Yareli 已对照 wiki）；
- Sevagoth / Sevagoth Prime：30 级护盾 285 / 320 → 335 / 370（Sevagoth 已对照 wiki）；
- Citrine Prime：与 Narin 同一次手工加入，极性同样错位，按客户端改正。

其余战甲与客户端一致（`--check` 复查无差异）。

工具：`tools/supplement_narin.py`（`--icons-root` 指向导出的 `Lotus/Interface/Icons`），
`tools/sync_warframe_client_fields.py --packages-bin <Packages.bin_H> [--check]`。测试：`tests/test_narin_20261012.py`。
