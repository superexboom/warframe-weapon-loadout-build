## Implementation

Both replay engines now carry delayed_radial_hit_event on Stats, only notify from their delayed-radial branch, refresh current victim status before the packet, and apply generic on-hit/on-crit after damage but before die() retires the victim. No notice occurs for a zero-damage packet. Generation-bound delayed packets are still discarded after host death. Crit probability matches radial packet semantics: body multiplier, full-victim crit and existing Enervate distribution; radial excludes Puncture. Enervate state updates remain unchanged.

Old native cores are rejected by DELAYED_RADIAL_EVENTS feature gating. mods_native fills the appended Stats field at the original attribute-order boundary, preserving exact Python/native apply_mods comparisons. app fingerprint now includes the producer registry and admission module. No combat-reference.json, extract.py, frontend, Battacor or CO data edits belong to this change.
