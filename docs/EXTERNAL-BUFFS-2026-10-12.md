## 二、武器配装：限定元素无法自动配装

配装页直接调用优化器，没有分析页那套「元素种子」回退；而 beam 搜索按单卡排名保留部分配装，像 Boltor Prime 限定病毒时，
冰冻 Mod 单独排名靠后，冰冻 + 毒素这一对永远凑不齐，于是报「无法装入对应的元素 Mod」。

`optimizer.optimize_for_element`：先正常搜索；元素约束失败时，按目标元素的组成部分各种入一张元素 Mod（先最强的，再最便宜的，
应对容量紧张）重新搜索；都不行才报原来的错误。分析页的种子列表（病毒 / 腐蚀）不变，烘焙结果不受影响。

Boltor Prime（快速档）十种元素目标：病毒、爆炸、磁力、毒气、辐射、冰冻、电击、毒素全部给出配装（之前病毒失败），
其中病毒 / 毒气 / 辐射走了种子回退（约 2–3 分钟）。

## 三、外部加成

### 1. 之前的问题

- **「终伤」一组实际没有按终伤算。** 黯然失色、分子填充、虚空重击、Unairu、仲裁都走 `WEAPON_PERCENT_BASE_DAMAGE_ADDED_POST_COALESCE`
  不带伤害类型，引擎对这种项只按基础（物理 / 天生元素）部分加成，元素 Mod 打出来的伤害完全不吃。配了满元素的武器上它们几乎没用。
- **数值或对象不对：** 虚空重击满能量是 +1000%、与膛线同乘区（写成 8×12.5% 的终伤）；Unairu 虚灵只加指挥官（增幅器）伤害，
  对战甲武器无效；庇佑圣约是 Mod 之后直接加的暴击率（弱点 ×4，上限 50% / 200%），之前按「暴击 +50%」与 Mod 相加；
  咆哮只加近战攻速，之前也加枪械射速；昼夜交替只加自身、近战无效；「强音增幅 Mallet」名字张冠李戴（Mallet 是一技能）；
  闪耀助燃对应的技能（Accelerant）已经被移除；死亡之眼是光环，之前放在技能里。
- 标签是「中文 英文」混写，不说加什么、在哪个乘区，也看不出对当前武器有没有用。小队光环几乎都没有。

### 2. 现在的结构

目录由后端下发（`/api/catalog` → `buildOptions.externalBuffs`），前端只负责渲染：

- **名称**：战甲技能写「战甲 · 技能」（Rhino · 战吼、Helminth · 战吼（注入））；强化 Mod 写「Ember · 狂热火球（火球强化）」；
  光环写 Mod 名（步枪增幅）。名字取本地化目录，不再显示英文。
- **每行三层**：名称 / 具体加成（随强度、人数实时更新，例如「步枪类基础伤害 +54%」）/ 乘区与限制说明。
- **控件**：战甲技能填施放者技能强度（%）；光环选携带人数 1–4（同一光环可叠加）；补给选元素；通用项直接填数值。
- **适用性**：按武器的客户端继承链判断，当前武器吃不到的项变灰并标「当前武器不生效」，引擎侧同样按 validType 过滤。
- **同族互斥**：原版与注入版（战吼、黯然失色、咆哮、消化滋养、暴怒突进）同时开只取较强者。
- **总收益**：开 / 关外部加成各跑一次实时解算，按击杀速度（KPM）比较，含额外命中与光环削甲。

### 4. 引擎

- `RUNTIME_FINAL_DAMAGE`：最终乘区，多个来源相乘，同时乘直伤和状态伤害基数（各一次）。
- `RUNTIME_FINAL_CRIT_DAMAGE`：加在最终暴击倍率上。
- `RUNTIME_EXTRA_HIT`（WFSim `docs/EXTRA_HIT.md` 口径）：每次武器命中后追加一次单一元素的伤害实例，等于该次命中 × 比例，
  派系再乘一次、部位再乘一次；命中击杀时不触发。必定触发的额外命中加进强制异常，它的持续伤害以额外命中伤害为基数
  （wiki：Extra Hit 的异常以额外命中伤害作为 Modded Base）。
- 光环削甲 / 削盾：`enemy_enhancements.auraArmourReduction / auraShieldReduction`，乘在等级缩放后的护甲 / 护盾上，与其他削甲相乘。
- 庇佑圣约、暴怒突进用现有的 `WEAPON_CRIT_CHANCE ADD`（Mod 之后加算）和 `WEAPON_CRIT_CHANCE_WEAKPOINT ADD`。

抽查（Lv170 钢铁、Boltor Prime / Rubico Prime / Nikana Prime 简配、30% 爆头，KPM 变化）：分子填充 +100% / +17% / +76%；
手枪增幅 0 / 0 / 0；死亡之眼只在 Rubico 生效（+6%）；钢铁充能、咆哮、暴怒突进只在 Nikana 生效；昼夜交替只在枪上生效；
剧毒鞭笞 +134% / +16% / +158%。
