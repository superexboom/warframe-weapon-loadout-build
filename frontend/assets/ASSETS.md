# Offline asset manifest

This directory is the complete frontend asset set for the first portable Riven tab. Runtime code must reference these local files only; none of them require a CDN or network request.

Source snapshots:

- WFHelper local clone: `b310f18aaa9351cae14b74a4409fbfced6d6b90e` (`https://github.com/WFHelper/WFHelper`, MIT repository license).
- WarframeRabbit local branch: `0d6569ad9362717617360ed61ce84580da5e353e`.
- `warframe-items` local clone: `6c90d27600ad98a47a4d4e99bb7550bddfea2217` (`https://github.com/WFCD/warframe-items`, MIT repository license). It supplies only `NightwaveLasGooPistolAugmentMod.jpg`, absent from the official export index.
- Warframe Companion 5.3.5.0 local APK extraction: `assets/Resources/common/mods`; these are Digital Extremes game UI assets, not third-party open-source artwork.

MOD coverage is deliberately based on the optimizer instead of the full game catalog: 387 frozen MOD records can match at least one of the 604 primary, secondary, or melee records and have a supported optimizer effect. Real art is available for all 387 records through 218 deduplicated files. The manual selector collapses tiered export aliases to one adjustable card and excludes PvP implementation shells.

Warframe names and game artwork remain property of Digital Extremes. The WFHelper MIT license covers that repository's code and original work; it does not replace Digital Extremes' rights in Warframe artwork.

## Deliberately excluded

- The 268 MiB official 2D export was not copied. Its `v2_weapons.json` mapping has 998 weapons and 824 unique icon paths; all 824 are present locally, but copying them would add 85,783,718 bytes before the UI uses any of them.
- Overframe frame layers were not copied. The visible build cards use the official Companion layers listed above.
- Screenshots, setup art, rank badges, glyph catalogs, and duplicate Riven icons were omitted.

When weapon portraits become visible in the UI, generate a deterministic subset from `v2_weapons.json` and the official asset index instead of importing the whole catalog.
